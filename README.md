# ahmedhossam.dev

Personal site and blog. Built with [Astro](https://astro.build), deployed on Cloudflare Pages.

## Dev

```bash
npm install
npm run dev
```

## Writing

Posts live in `src/content/writing/`. Set `draft: true` while writing, `draft: false` to publish.

```bash
git add .
git commit -m "publish: post title"
git push
```
